# SEOForge v0.2 plan and delivery

## Goals

Expand the v0.1 skills-only SEO package with missing measurement, architecture, content and diagnosis workflows; deepen weak areas; provide original visual documentation; preserve the general-purpose scope.

## Implementation

1. Add 12 independent skills: Search Console, traffic diagnosis, analytics, conversion tracking, site architecture, crawler logs, SERP research, experiments, foundation context, content writing, news/Discover and Bing. Each must name necessary evidence and the unavailable-data behaviour.
2. Expand eight existing skills: on-page internal links; content decay; technical JavaScript/mobile/accessibility; programmatic content quality; AI entity and bot checks; competitor link recovery; mobile performance; e-commerce faceted navigation.
3. Update the router, README catalog, manifest version and CI package name. Add original SVG illustrations and an illustrative GIF that is clearly labelled. Link DevFlowForge as a companion.
4. Validate all skill frontmatter, scope limits, archive contents, offline helper tests and absence of user-specific business presets. Verify README links and image rendering in GitHub.

## Later versions

- Optional verified Search Console, analytics, PageSpeed and Bing connections.
- Polite crawl tooling and historical snapshots, with explicit limits and resource controls.
- End-to-end skill evaluations on real accessible sites and exported datasets.
- Additional publisher listing and demo material if submitting to a public plugin directory.

A skill guides an available tool; it does not itself authenticate to Google or run a background service.
